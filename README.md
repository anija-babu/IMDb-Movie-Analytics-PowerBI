# 🎬 IMDb Movie Analytics Dashboard | Power BI

##  Project Overview

The **IMDb Movie Analytics Dashboard** is an interactive Power BI project designed to analyze movie ratings, genre distribution, box office revenue, director performance, and audience engagement.

The dashboard provides insights into movie performance by combining IMDb ratings, audience votes, gross revenue, and release trends through interactive visualizations.

This project demonstrates data cleaning, transformation, DAX calculations, and data visualization using Microsoft Power BI.

##  Data Source: 

https://www.kaggle.com/datasets/harshitshankhdhar/imdb-dataset-of-top-1000-movies-and-tv-shows


##  Project Objectives

- Analyze movie performance based on IMDb ratings and gross revenue.
- Identify the highest-rated movies and directors.
- Explore movie distribution across different genres.
- Examine movie release trends over the years.
- Investigate the relationship between IMDb ratings and box office revenue.
- Analyze the relationship between IMDb ratings and audience votes.
- Develop an interactive dashboard to support data exploration.

  

##  Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization

- **DAX** – Calculated measures and KPI development

Key data preparation activities included:

##  Key Insights

The dashboard highlights the following observations:

- **Average IMDb Rating:** The 999 movies in the dataset have an average IMDb rating of 7.95.
- **Audience Engagement:** The movies have approximately 274 million combined IMDb votes.
- **Box Office Performance:** Total recorded gross revenue is approximately $56.54 billion.
- **Genre Distribution:** Drama is the largest displayed genre category, representing approximately 24.22% of the movies.
- **Highly Rated Movies:** *The Shawshank Redemption* and *The Godfather* are among the highest-rated titles, with IMDb ratings of 9.3 and 9.2, respectively.
- **Release Trends:** The dashboard shows increased movie releases in later decades compared with earlier periods.
- **Director Performance:** Frank Darabont has the highest displayed average IMDb rating at 9.0.
